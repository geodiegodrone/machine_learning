# Portfolio Guide

## Positioning

This repository should communicate a progression from basic machine-learning exercises toward professional, reproducible ML engineering.

## Recommended Narrative

1. Data understanding and cleaning.
2. Feature engineering.
3. Model comparison.
4. Validation strategy.
5. Error analysis.
6. Reproducibility.

## Doctoral-Level Upgrade Path

- Add formal experiment tracking.
- Add statistical comparison of model families.
- Add uncertainty estimates.
- Add reproducible pipelines for each notebook.
- Add dataset cards.
- Add model cards.
- Add failure-mode analysis.

## Reviewer Checklist

- Can a reviewer identify the objective of each notebook?
- Are train/test files documented?
- Are metrics reproducible?
- Are random seeds fixed?
- Are limitations explicit?
