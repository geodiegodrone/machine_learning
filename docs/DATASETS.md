# Dataset Notes

## Dengue Dataset

The `actividad1` folder includes dengue train/test features and labels used in coursework. Future work should add a complete data dictionary, source citation, license notes, and leakage checks.

## Notebook Data Hygiene

When adding new datasets:

- document source and license,
- preserve raw files,
- store derived data separately,
- explain target variable construction,
- document missing-value handling.
